ERP Feedback Helper

Fills the IIT KGP end-term feedback form for all your courses, then opens your admit card. You only pick your courses and type each captcha.

1 · Install (once)

Laptop, easy way: show your bookmarks bar (Ctrl+Shift+B), then drag this button onto it:

KGP Feedback ⚡

Bookmark brings you back to this page? You saved the page instead of the button. Delete that bookmark and use the Copy the code steps below. The saved bookmark's URL must start with javascript:.

If dragging doesn't work:

  2. Right-click the bookmarks bar → Add page… (Chrome) or Add bookmark…
  3. Name it KGP Feedback, paste the code into the URL field, save.

2 · Use

  1. Log in to ERP and click the KGP Feedback bookmark on any ERP page. It checks your login and opens the Feedback Form by itself.
  2. Untick any course you don't take, pick your rating, workload and pace levels, press Start.
  3. For every course it opens each teacher one by one and fills the form.
  4. Taught you? Type the captcha and press Enter. Didn't? Click Skip, didn't teach me. It moves on by itself. Teachers you already submitted are skipped.
  5. After the last course, your admit card page opens.

Good to know

It only clicks inside your own open ERP page. Nothing gets sent anywhere, and it never submits for you. Profs do read these, so set the levels to what you actually think. It saves you clicks, but the opinion should still be yours.

Works on laptop browsers (Chrome, Edge, Firefox, Brave). If ERP changes the form and a question is skipped, the panel says so and you can fill that one by hand.
